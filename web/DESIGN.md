# web — design note

shadcn/ui defaults, neutral base, dark by default (`.dark` on `<html>`), light toggle in the sidebar.
No custom palette, typefaces, illustrations or motion: the console stays out of the way.
14px body, 12px metadata, `font-mono` for ids, models, tokens, YAML, logs and timestamps.
Neutral theme is the only accent; colour is reserved for status (running, stopped, created, error).
Accessibility is the visual system: visible focus rings, real labels, 44px touch targets, reduced motion respected.
